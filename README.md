# OrgERP.github.io
As part of ACM UTSA's RowdyHack, one of the largest hackathons in San Antonio, I designed a Mock/Test of an ERP System 
to assist organizations in managing and moving resources. In the 24 hour time frame alloted for the event, I utilized
my skills in HTML/CSS to design an interactive website where information could be submitted. The project has many areas
in which necessary features for a legitimate platform could be added, but due to the short time frame, I only added essential
features to highlight the system.
